QEVION is a governed AI execution platform: you describe a task, the Router picks a model, an execution runs it (single shot, a multi-stage template, or the tool-using agent), and every run is a stored record you can inspect.
  1. Organise — create a workspace and a project (left rail) so runs carry context.
  2. Run — write the task in the composer; pick a project / template; press Run.
  3. Read — the answer appears with its facts (provider, mode, learned context); raw JSON is one click away.
  4. Inspect — Runs lists every execution with project and mode; Models shows runtime availability; Usage your budget; Capabilities skills, memory, webhooks.

You have no workspace yet. A workspace groups projects; a project gives runs their context.

You can also run a task right away without one — the run will simply carry no project.
